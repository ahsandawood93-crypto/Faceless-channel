How to run a video through the pipeline
1

Create a topic folder

Choose a topic. Create the folder and copy template files.

mkdir -p videos/letter-a
cp videos/_template/* videos/letter-a/
2

Agent 01 — Topic Research

Open agents/01-topic-research.md. Paste the scoring prompt into Claude with your topic idea. Fill in topic.json. Set status: "idea". Composite score must be ≥ 7.0 to proceed.

3

Agent 02 — Trend Research

Open agents/02-trend-research.md. Research keywords, competitors, differentiation angle. Write research.json. Update status: "research".

4

Agent 03 — Script Writing

Open agents/03-script-writing.md. Generate the full 6-section script (Hook → Objective → Core → Reinforce → Recap → CTA). Write script.md. Update status: "script".

5

Agent 04 — Voice Production

Open agents/04-voice-production.md. Generate SSML script, voice brief, produce audio. Write voice.json. Listen through, set approved: true. Update status: "voice".

6

Agent 05 — Visual Planning

Open agents/05-visual-planning.md. Plan every scene with AI image prompts, b-roll list, edit plan. Write visuals.json. Update status: "visuals".

7

Agent 06 — Thumbnail Creation

Open agents/06-thumbnail-creation.md. Generate 10 concepts, rank, write AI image prompt for winner. Write thumbnail.json. Update status: "thumbnail".

8

Agent 07 — Upload Preparation

Open agents/07-upload-prep.md. Generate title, description, chapters, tags, playlist assignment. Write upload.json. Update status: "ready_to_upload".

9

Human gate — review and upload manually

Work through the checklist in upload.json. Upload in YouTube Studio. Select Made for Kids: Yes. Fill in published_url. Update status: "published".

★

Update the dashboard

Edit the VIDEOS array in dashboard/index.html to reflect the new status. The dashboard reads from this embedded array — no server required.

Check before every publish cycle — policies change
  • Made for Kids / COPPA: Select "Yes — Made for Kids" in YouTube Studio for every upload. Comments and personalized ads are disabled. CPMs are lower than standard content.
  • AI Disclosure: YouTube requires disclosure when AI materially contributed to content. Include this in each video description. Verify current policy at youtube.com/howyoutubeworks before publishing.
  • Copyright: All music, characters, and visuals must be original or properly licensed. Never use copyrighted material without permission.
  • Human approval gate: Never upload, publish, post comments, spend money, or change channel settings without explicit approval from Ahsan.
