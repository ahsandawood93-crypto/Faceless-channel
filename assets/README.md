# Assets

| Folder / file | What to put there | Used by |
|---|---|---|
| `characters/minsa.png`, `characters/mana.png` | One clear, full-body image per character on a plain background, ~1024 px or larger, same 3D style for both. These are Veo's reference images, so consistency depends on them. | Stage 3 |
| `music/` | A few royalty-free background tracks (`.mp3` / `.wav`). You need the rights to use them on YouTube (e.g. YouTube Audio Library). | Stage 4 |
| `fonts/` | One rounded, child-friendly `.ttf` font (e.g. Baloo 2 or Fredoka from Google Fonts, both under the OFL licence). | Stage 4 |
| `intro.mp4`, `outro.mp4` | Optional short intro/outro, 1080p 16:9. Skipped if missing. | Stage 4 |
